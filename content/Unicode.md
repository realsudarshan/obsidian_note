Key value pair dictionary containing "any character"="code point"
where "any character"=any kind of character used in computer including other language like devanagari or english
code point="any specific code of corresponding character 
Example:

- **Character:** ñ
    
- **Unicode Code Point:** `U+00F1`
The letter `A` is `U+0041`. The "Face with Tears of Joy" emoji 😂 is `U+1F602`
Before Unicode, different systems used different maps. A number that meant "A" on one computer might mean "平" on another, leading to broken text (mojibake).
