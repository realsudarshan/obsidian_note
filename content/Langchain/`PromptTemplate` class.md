A class provided by langchain to make prompt templete
**PromptTemplate** is a class in LangChain used to create dynamic, reusable prompts with placeholders, which you fill at runtime to generate specific queries. Unlike simple f-strings, PromptTemplate offers validation, reusability, and better integration with LangChain’s ecosystem. It supports maintaining consistency and reduces runtime errors by ensuring that all placeholders are accounted for before execution. For example, in a research assistant tool, you create a prompt template asking to summarize a paper with placeholders like paper title, style, and length, dynamically filled by the user input.
