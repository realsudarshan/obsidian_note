Extra disks you can attach to the VM **besides the boot disk**.
Used for storing application data, databases, files, backups, etc.
like plugging in a **D: drive / external hard drive**.
- Types:
    
    - **Standard persistent disk** → Cheaper, slower, for backups/logs.
        
    - **Balanced persistent disk** → Good general-purpose choice.
        
    - **SSD persistent disk** → Faster, more expensive, for high IOPS workloads.
        
    - **Local SSD** → Physically attached to the VM host, super-fast but **temporary** (data lost if VM stops).
