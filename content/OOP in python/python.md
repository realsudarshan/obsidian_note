Virtual environment
### 💡 Pro Tip: Never make this mistake again (The Guardrail)

If you want to completely protect yourself from ever accidentally installing packages globally, you can tell `pip` to **refuse** to install anything unless a virtual environment is active.

You can do this by adding an environment variable to your Windows system, or just run this command in your PowerShell to set it for your current session:

PowerShell

```
$env:PIP_REQUIRE_VIRTUALENV="true"
```
