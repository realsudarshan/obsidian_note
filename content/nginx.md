# Nginx

Nginx (pronounced "engine-x") is a popular open-source web server that can also be used as a reverse proxy, load balancer, mail proxy, and HTTP cache. 

## Key Features
- **High Performance:** Capable of handling a high volume of concurrent connections.
- **Reverse Proxy:** Directs client requests to the appropriate backend server.
- **Load Balancing:** Distributes incoming traffic across multiple servers (e.g., Round Robin, Least Connections, IP Hash).
- **Static Content Serving:** Extremely efficient at serving static files like HTML, CSS, JavaScript, and images.

It is widely used in modern web architectures to ensure high availability and reliability.
